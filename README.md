# 家庭账本

手机优先的家庭记账单页应用。导入微信、支付宝、京东账单，自动分类并统计。

**在线使用：** https://gao-wf.github.io/family-ledger/

## 功能

- 导入微信 / 支付宝 / 京东账单，支持 CSV、TSV、XLSX、XLSM
- 支持美团月付、抖音月付、京东白条、云闪付（手动记账）
- 12 类自动分类，日 / 月统计、预算、日历明细
- 手动记一笔、编辑、撤销导入、备份恢复
- 纯前端单文件应用，无需安装，添加到手机主屏幕即可像 App 一样使用

## 数据说明

所有账本数据保存在**各设备浏览器的本地存储（localStorage）**中，**不会上传到服务器或 GitHub**。

因此：
- 换电脑或换手机时，数据不会自动跟随，需要在「设置 — 数据管理」中导出备份，再到新设备导入
- 清除浏览器数据会一并清空账本，请定期备份

## 技术说明

单文件 `index.html`，零第三方依赖。XLSX 解析使用纯 JS 实现（ZIP + DEFLATE 解压 + XML 解析），不依赖 `DecompressionStream` 等新 API，因此兼容微信内置浏览器和较旧的安卓内核。
